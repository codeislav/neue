# Neue — redesign for YouTube

A Chrome extension that redesigns the YouTube interface in a glass style: the header, the home page, channel pages and fullscreen mode. Settings are in Chrome's side panel and apply instantly.

- Glass header buttons for Shorts, Subscriptions and You; "My channel" and "Studio" buttons; adjustable search bar width
- Home page grid with 1 to 12 videos per row
- Pop-up player for videos on the home page and channel pages, sized to the video
- Comments as a card over the video in fullscreen
- Channel pages with the banner, avatar and channel info in one card, at full window width
- Light and dark theme, following YouTube's theme
- Interface in 17 languages, following YouTube's language

**[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/pbhodocjfoobobjkkenimpibhbedjkpb)**
